# Owner claims and professional credentials

Phase 8 defines review boundaries for high impact actions.

An owner or manager can manage a property only when an active, property scoped membership has `management_claim_approved` assurance. Every claim decision requires a reviewer, timestamp and reason.

Professional credentials are separate from ownership. A credential is usable only when approved, within its validity window, in scope for the issue category and free of a declared property conflict. Expired, revoked, rejected or out of scope credentials cannot certify findings.

This phase stores evidence references and decision rules; private upload and object storage arrive in Phase 9. Decisions are intended to append audit entries and must not be influenced by owner payments. Persistence and a reviewer provider are still required before live access.
