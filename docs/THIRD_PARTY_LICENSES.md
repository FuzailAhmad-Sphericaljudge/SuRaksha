# Third-party data and media register

No third-party property dataset or Google photo is bundled in the repository. Current demo property names and images are fictional project assets.

Before adding a provider, record its owner, source URL, license or contract, permitted fields, image-display terms, attribution requirement, refresh interval, deletion process and production API key owner. Google Maps or Places content must be fetched and displayed under the applicable platform terms rather than copied into the repository.

User-uploaded media requires uploader confirmation that they may submit it. Reviewer approval concerns publication suitability; it does not transfer copyright ownership to SafePG.
